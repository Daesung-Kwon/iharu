# Data safety 답안 초안 (i하루, com.iharu.app)

작성일: 2026-11-26 (Asia/Seoul). Play Console에 입력하지 않음. 사용자가 초안을 확인한 뒤 별도 승인으로 입력한다.

전제: 앱은 계정을 만들지 않고, 일정·핀·보상 데이터는 기기에만 둔다. 분석 SDK, 광고 SDK, 자체 서버 전송이 없다. App Store Connect App Privacy는 2026-11-18 기준 Data Not Collected. 개인정보처리방침: https://iharu.wodybody.com/privacy.html

개요 질문

- 앱이 필수 또는 선택 유형의 사용자 데이터를 수집하는가? **아니요.**
- 수집한 데이터를 제3자와 공유하는가? **해당 없음 (수집 없음).**
- 수집한 데이터를 암호화해 전송하는가? **해당 없음.**
- 사용자가 데이터 삭제를 요청할 수 있는가? **해당 없음.** (기기 내 데이터는 설정에서 사용자가 직접 지우거나 앱을 삭제한다.)

데이터 유형 (모두 수집하지 않음으로 답한다)

- 위치, 개인정보(이름·이메일·전화번호 등), 금융, 건강, 메시지, 사진·동영상, 오디오, 파일·문서, 캘린더, 연락처, 앱 활동, 웹 탐색, 앱 정보 및 성능, 기기 또는 기타 ID: **수집하지 않음.**

헷갈리기 쉬운 항목과 이유

- **알림:** 로컬 알림만 쓴다. 푸시 토큰을 우리 서버로 보내지 않는다. Data safety의 「수집」이 아니다.
- **인앱 결제:** 결제는 Google Play가 처리한다. 앱은 구매 완료 여부만 기기에서 확인한다. 카드번호·계좌를 앱이 수집하지 않는다.
- **백업/복원:** 사용자가 파일 선택기(`expo-document-picker` / 공유 시트)로 로컬 JSON을 내보내거나 가져온다. 우리 서버로 올라가지 않는다. Android 13+ 에서는 레거시 저장소 권한을 요청하지 않는다 (`maxSdkVersion=32`).
- **광고 ID:** 사용하지 않으며 권한을 매니페스트에서 제거한다.

보안 관행 (수집 없음이어도 묻는 경우)

- 데이터는 전송하지 않으므로 전송 중 암호화 질문은 「해당 없음」.
- 가족이 쓰는 앱이지만, 아동 개인정보를 수집하지 않는다. Families 선언과 모순되지 않게 유지한다.

입력 시 주의

- 설문 결과가 「데이터가 수집되지 않습니다」로 스토어에 보여야 한다.
- 개인정보처리방침 URL을 이 답과 같게 둔다. 방침이 광고·추적을 말하면 안 된다 (현재 페이지는 광고 없음).
