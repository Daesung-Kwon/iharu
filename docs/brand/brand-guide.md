## 1. 원칙 (Steve Jobs 기준)
1. **하나만:** accent 색 1개, 아이콘 세트 1개, 그림자 1개, 마스코트 1명.
2. **덜어내기:** 카드에 테두리, 색 배경, 그림자를 동시에 쓰지 않습니다. 셋 중 하나만 씁니다(기본은 흰 카드 + 그림자).
3. **혼내지 않기:** 아이가 보는 상태는 빨강으로 칠하지 않습니다. "시간 지남"은 amber 작은 태그로만 표시합니다.
4. **귀여움은 한 곳에:** 마스코트는 축하, 빈 화면, 온보딩에만 나옵니다. 리스트나 버튼에는 넣지 않습니다.

## 5. 모양·선·그림자
- **스트로크:** 아이콘 2px @24(비율 1/12). 화면에서 1.5px 미만이나 2.5px 초과 선은 쓰지 않습니다. 구분선만 1px.
- **반경 3종:** 카드·시트 24, 타일·칩·입력 14–16(타일 크기의 30%), pill 999. 모달 대화상자는 32.
- **그림자 1종:** `0 4 16 rgba(45,52,54,.06)` + `0 1 2 rgba(45,52,54,.04)`. 탭바만 `0 6 24 / .10`.
- **간격:** 4·8·12·16·24·32. 화면 좌우 16, 카드 안쪽 16, 카드 사이 12.

## 6. 아이콘 그리드 규칙 (원본: `icons/svg/ih-*.svg`)
| 항목 | 규칙 |
|---|---|
| 캔버스 | 24×24 viewBox. 1단위 = 1pt @24 |
| 라이브 영역 | 가운데 20×20(사방 2 여백). 원형은 지름 17–18, 정사각형은 16×16, 세로·가로로 긴 형태는 20까지 |
| 스트로크 | 2, `stroke-linecap: round`, `stroke-linejoin: round`. 열린 끝은 모두 둥글게 |
| 모서리 | 도형 내부 모서리 반경 1.5–3(최소 1.5). 뾰족한 꼭짓점 금지(별·삼각형도 round join) |
| 듀오톤 | 외곽선(currentColor) + **틴트 면 하나**(currentColor, opacity .18). 작은 디테일 점은 solid 지름 2–2.4. 그 외 채움은 없음 |
| 겹침 | 겹치는 두 형태는 2pt 간격으로 앞 형태가 뒤를 끊음(mask). 예: homework 연필, math 블록, friend 얼굴 |
| 광학 보정 | 원형·삼각형은 사각형보다 0.5–1 크게. 무게 중심이 가운데에서 1pt 이상 벗어나지 않게. 속도선 같은 보조 선은 opacity .45 |
| 크기 | 20(리스트 보조) · 24(기본) · 28(타일 52). 18 이하는 타일 32에서만 쓰고, 틴트를 빼도 됨 |
| outline vs filled | **기본은 outline + 틴트.** filled(면 100%)는 "선택됨·켜짐" 상태 한 곳만(활성 탭, 선택된 활동 칩). 같은 줄에 두 스타일을 섞지 않음 |
| 색 | 단독은 `ink`(기본) 또는 `ink2`(보조). 타일 안에서는 해당 hue의 ink. 코랄 아이콘은 활성 상태에만 |
| 타일 | 52(r16, 아이콘 28) Activity 그리드 · 46(r14, 24) Today·Plan 카드 · 32(r10, 18) 인라인 배지. 배경은 hue tint, 테두리·그림자 없음 |
| 이름 | `ih-{emojiKey}`(활동) / `ih-{의미}`(UI) / `ih-{의미}-fill`(활성 탭). 활동은 이모지 키를 그대로 써서 데이터 마이그레이션 없이 교체 |
| 구성 | P0 기본 활동 8 + P1 앱 UI 9 + P2 피커 전용 20 + 시스템(탭 8 + 설정 행 14) 22 = **59** |
